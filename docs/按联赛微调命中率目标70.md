# 按联赛微调单场推荐命中率（目标 70%）

## 思路

- 在**全量评估**时按联赛统计「单场推荐」的 (推荐概率, 是否命中)。
- 对每个联赛计算：**达到目标命中率（默认 70%）所需的最低推荐概率** `min_prob_70`：即仅保留「推荐概率 ≥ 该值」的场次时，该联赛历史命中率 ≥ 70% 且样本数 ≥ 最小样本数（默认 20）。
- **今日推荐**时若存在联赛参数文件，则对该联赛只展示 `rec_prob >= min_prob_70` 的场次；无 `min_prob_70` 的联赛不额外提高门槛。

这样在「有门槛」的联赛里，展示的推荐理论上可接近 70% 命中率；其余联赛仍按全局 `min_prob` 等条件筛选。

## 使用步骤

### 1. 生成联赛推荐参数（建议全量）

```bash
python3 main.py jc-predictions-eval --all-time --export-league-rec-params data/jc_league_rec_params.json
```

- 会写入 `data/jc_league_rec_params.json`，内含各联赛的 `n`、`single_rec_accuracy`、`min_prob_70`。
- 控制台会打印「单场推荐按联赛」表格，标出哪些联赛「达 70% 门槛 X.XX」、哪些「历史无法达 70%」。

### 2. 今日推荐自动按联赛门槛过滤

- 配置文件默认：`JC_REC_LEAGUE_PARAMS_PATH = data/jc_league_rec_params.json`。
- 若该文件存在，`jc_recommend_bet_slip`（今日推荐）会加载之；对 `min_prob_70` 非空的联赛，只保留 `rec_prob >= min_prob_70` 的场次。
- 无需改代码，生成一次参数文件后，API/命令行今日推荐都会生效。

### 3. 高置信门槛（抬高高置信命中率）

- `JC_REC_HIGH_CONFIDENCE_MIN_PROB`（默认 **0.65**）：推荐概率 ≥ 此值才标为「首选/高置信」。设为 0.65 时首选更少但命中率更高；若希望更多场次进首选可调回 0.60。

### 4. 可选配置（.env）

| 变量 | 含义 | 默认 |
|------|------|------|
| `JC_REC_LEAGUE_PARAMS_PATH` | 联赛推荐参数 JSON 路径 | `data/jc_league_rec_params.json` |
| `JC_REC_TARGET_HIT_RATE` | 目标命中率（用于计算 min_prob_70） | 0.70 |
| `JC_REC_LEAGUE_MIN_N` | 计算门槛时联赛最少样本数 | 20 |
| `JC_REC_HIGH_CONFIDENCE_MIN_PROB` | 高置信门槛（≥此值标为首选） | 0.65 |

- 若希望更多联赛出现「达 70% 门槛」，可把目标降到 0.65（`JC_REC_TARGET_HIT_RATE=0.65`），再重新执行步骤 1 生成参数文件。

## 当前数据下的表现

- 全量评估后，多数联赛在「推荐概率 0.50～0.80、且样本≥20」的子集内**无法达到 70%**，因此 `min_prob_70` 为 `null`，今日推荐对这些联赛不提高门槛。
- 目前仅有**法甲、日职、法乙**等少数联赛能算出「达 70% 门槛 0.68」；今日推荐中这些联赛只会出现推荐概率 ≥ 68% 的场次，理论上更接近 70% 命中率。
- 若希望更多联赛参与「按联赛 70%」过滤，可适当降低 `JC_REC_TARGET_HIT_RATE`（如 0.65）并重新导出联赛参数。

## 评估对比与伤停权重微调

- 若调整伤停权重或其它参数后**命中率下降**，可先全量回退伤停权重到 3.0，再小步按联赛微调。
- 如何做「优化前 / 优化后」对比、看**哪些档位变化最大**、以及按联赛**小幅**上调伤停权重的建议，见：[竞彩评估对比与伤停微调建议.md](竞彩评估对比与伤停微调建议.md)。

## 与「细分覆盖」的关系

- **按联赛 min_prob_70**：按**联赛**维度提高推荐概率门槛，目标 70%。
- **细分覆盖（segment-stats）**：按「联赛×推荐类型×概率区间」在差细分改推胜/负，默认关闭。
- 两者可同时使用：先按联赛门槛过滤，再在剩余场次上按需启用细分覆盖。

## 单场推荐命中率还能继续提高吗？

可以。分两类：**你看到的「单场推荐」统计数字** 和 **模型本身**。

### 1. 提高「单场推荐」统计数字（推荐口径）

- **全量单场推荐**目前约 55.4%；若只统计/只展示「高置信」子集，命中率会更高：
  - 推荐概率≥65%：约 58.9%
  - 推荐概率≥70%：约 67.1%
- 做法：
  - **按联赛门槛**：上面步骤 1–2，生成 `jc_league_rec_params.json` 后，今日推荐只展示 `rec_prob >= min_prob_70` 的场次，有门槛的联赛会接近 70%。
  - **抬高高置信门槛**：`JC_REC_HIGH_CONFIDENCE_MIN_PROB=0.68` 或 0.70，只把「首选/高置信」标在更高概率的场次上，高置信子集命中率会再抬一点。

### 2. 提高模型本身的单场推荐命中率（把 55.4% 整体抬上去）

| 方向 | 操作 | 说明 |
|------|------|------|
| 按联赛校准 | `calibrate-probs --by-competition` | 联赛专属 Platt 参数，概率更准 → 推荐更准 |
| 伤停/联赛参数 | 用 2021–2025 做 lineup-key-absent-analysis → merge-injury-params，再按 [竞彩评估对比与伤停微调建议](竞彩评估对比与伤停微调建议.md) 小步调 | 伤停权重合适可减少系统性偏差 |
| 联赛 DC/平局参数 | 在 `predict_league_params.json` 里按联赛设 `PREDICT_DC_RHO`、`PREDICT_DRAW_BOOST_COEF` 等 | 平局多的联赛调平局相关参数 |
| 细分覆盖（可选） | `jc-predictions-eval --export-segment-stats` 生成 JSON，再在推荐逻辑里加 `--segment-stats` 读入 | 差细分改推胜/负，默认关闭，需评估是否提升 |
| 期望进球/特征 | 见 [模型改进方向](模型改进方向.md)：xG 混合、近期权重、联赛参数等 | 中长期，从根源上提高概率质量 |

### 3. 建议执行顺序

1. **先做**：生成联赛推荐参数并让今日推荐用上（步骤 1–2），必要时把 `JC_REC_HIGH_CONFIDENCE_MIN_PROB` 调到 0.68。
2. **再做**：`calibrate-probs --by-competition`，用 2021–2025 数据；重跑 2026 预测后再 `jc-predictions-eval` 看单场推荐是否提升。
3. **按需**：用伤停分析 + 评估对比文档，对部分联赛小幅调伤停权重，每次改完都跑一次 2026 评估对比，命中率不升就回退。

## 场次 vs 命中率：为什么「只统计模型推荐」到 70% 时场次会少？

把「只统计模型推荐」的命中率抬到约 70%，本质是**只保留推荐概率≥某阈值（如 70%）的场次**再算命中率。阈值越高，命中率越高，但**符合条件的场次越少**，这是同一套概率下的必然结果。

### 当前 2026 典型分档（参考）

| 推荐概率门槛 | 约场次 | 约命中率 |
|-------------|--------|----------|
| ≥50%        | ~603   | ~58%     |
| ≥60%        | ~591   | ~58%     |
| ≥65%        | ~290   | ~61%     |
| ≥70%        | ~76    | ~67%     |
| ≥75%        | ~69    | ~67%     |

所以：**要命中率接近 70%，当前只能推约 70～80 场（≥70% 档）；场次一多，命中率就会掉到 60% 多。**

### 若你希望「场次多一些」

有两种思路：

1. **接受略低的命中率，换更多场次**  
   - 把**今日推荐 / 高置信**用的概率门槛**调低**，例如：
     - `JC_REC_DEFAULT_MIN_PROB=0.55` 或 `0.58`（今日推荐默认最低概率）
     - `JC_REC_HIGH_CONFIDENCE_MIN_PROB=0.62` 或 `0.60`（高置信/首选标为「高」的门槛）
   - 这样「模型推荐」的场次会明显增多，但命中率会降到约 60%～65%，而不是 70%。

2. **维持 70% 目标，从模型侧多推高置信场次**  
   - 继续做模型与数据优化（校准、伤停、联赛参数、特征等），让**更多场次**的推荐概率自然落在高区间（如 ≥65%、≥70%），且这些场次里命中比例保持较高。  
   - 这样在「只统计模型推荐」时，既能保持约 70% 命中率，又能让**被推荐的场次数**慢慢增多。

### 可调配置小结

| 配置项 | 作用 | 门槛调高 → 场次少、命中率高；门槛调低 → 场次多、命中率降 |
|--------|------|-----------------------------------------------------------|
| `JC_REC_DEFAULT_MIN_PROB` | 今日推荐最少要多少概率才展示（默认 0.60） | 可改为 0.55～0.58 以增多场次 |
| `JC_REC_HIGH_CONFIDENCE_MIN_PROB` | 多少概率以上标为「高置信/首选」（默认 0.68） | 可改为 0.62～0.65 以让更多场次进首选 |
| `jc_league_rec_params.json` 的 `min_prob_70` | 按联赛过滤：只展示 ≥ 该联赛门槛的场次 | 按联赛调，可部分联赛放宽以增场次 |

结论：**「只统计模型推荐的命中率到 70%」和「推荐场次多」是同一套概率下的权衡**；要么降门槛多推几场、接受命中率略降，要么维持高门槛、优先保 70%，再靠模型优化慢慢把「高置信场次数量」做上去。
