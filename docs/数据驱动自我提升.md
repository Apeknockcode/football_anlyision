# 数据驱动自我提升：根据未命中复盘提升命中率

## 思路

不再用固定启发式（如「让负概率<0.65 就出负」），而是：

1. **复盘**：用历史数据统计「在什么情况下推荐什么、命中了多少」——按 **联赛 × 推荐类型 × 概率区间** 细分。
2. **判断**：对每一场，先得到**基线推荐**（纯概率最高的一项），再查该细分的历史命中率。
3. **自我提升**：若该细分历史命中率**明显偏低**（低于阈值且样本足够），则在该细分下改为推荐**胜/负**（不推让球），从而减少在「历史表现差」场景下的让球误推。

## 一键自动（推荐）

希望**自动用复盘结果调高命中率**时，执行：

```bash
python3 main.py jc-segment-auto
# 或
./scripts/jc-segment-auto.sh
```

该命令会：① 全量复盘并导出细分命中率到默认路径 `data/jc_rec_segment_hit_rates.json`；② 用细分覆盖再跑一遍评估，展示「数据驱动自我提升」后的命中率；③ 若未启用则提示在 `.env` 中设置 `JC_REC_USE_SEGMENT_STATS=true`。设置后，**今日推荐**与推荐接口会自动读取该文件，在历史表现差的细分改为推荐胜/负。

## 使用流程（分步）

### 第一步：导出细分命中率（复盘）

在全量评估时，用**基线推荐**（只取概率最高的一项，不做任何启发式）统计每个细分的命中率，并写入 JSON：

```bash
python3 main.py jc-predictions-eval --all-time --export-segment-stats data/jc_rec_segment_hit_rates.json
```

生成文件示例：`data/jc_rec_segment_hit_rates.json`，内容为 `segments`：键为 `联赛|推荐类型|概率区间`（如 `西甲|让负|0.60-0.65`），值为 `{ "n", "hit_rate" }`。

### 第二步：用细分数据做推荐与评估（自我提升）

后续评估或今日推荐时，读入该文件；在**命中率低于阈值**且**样本数 ≥ 最小样本**的细分下，将让球推荐改为胜/负：

```bash
python3 main.py jc-predictions-eval --all-time --segment-stats data/jc_rec_segment_hit_rates.json
```

- 未传 `--segment-stats`：按当前逻辑（基线 + 启发式）评估，不读细分文件。
- 传 `--segment-stats`：读入细分命中率，在低命中率细分中改为推荐胜/负。

**配置（环境变量或 config.py）：**

- `JC_REC_SEGMENT_STATS_PATH`：细分命中率 JSON 路径，默认 `data/jc_rec_segment_hit_rates.json`。今日推荐接口会按该路径自动加载（若文件存在）。
- `JC_REC_SEGMENT_HIT_RATE_FLOOR`：命中率低于此值的细分才改为胜/负，默认 **0.42**（只修正明显差的细分；0.52 会覆盖过多、全量命中率可能下降）。
- `JC_REC_SEGMENT_MIN_N`：细分至少多少场才参与覆盖，默认 **50**。

### 第三步：定期更新细分数据

补新赛果或新赛季后，可重新跑第一步，覆盖同一文件，再继续用第二步做评估与推荐。

## 行为说明

- **基线推荐**：在评估里按「主胜/平/客胜/让胜/让平/让负」取概率最高的一项，用于统计各细分的命中率，不做启发式。
- **覆盖规则**：仅当 `(联赛, 推荐类型, 概率区间)` 的 `hit_rate < JC_REC_SEGMENT_HIT_RATE_FLOOR` 且 `n >= JC_REC_SEGMENT_MIN_N` 时，在该细分下将**让胜/让负**改为**胜/负**；其它推荐类型不变。
- **今日推荐**：若存在 `JC_REC_SEGMENT_STATS_PATH` 对应文件，`jc_recommend_bet_slip` 会加载并在推荐时应用上述覆盖，与评估逻辑一致。

## 效果与建议

- 全量不传 `--segment-stats` 时，单场推荐命中率约 **52.8%**（基线）。
- 传 `--segment-stats` 且使用默认 0.42 / 50 时，约 **51.4%**（在明显差细分改为胜/负，全量略降但差细分更保守）。
- 若希望全量命中率尽量不降，可**不传** `--segment-stats`，仅用导出的 JSON 做**人工复盘**（看哪些联赛×推荐类型×概率区间命中率低），再在策略或展示上做筛选。
