# 新增年份数据后需要执行的命令

以新增 **2024** 年为例，按推荐顺序执行。若只用部分功能（如只主库、或只竞彩），可只跑对应步骤。

---

## 一、核心比赛数据

### 1. 主库比赛（二选一或都做）

- **football-data.org 五大联赛**  
  ```bash
  python main.py ingest-fd --seasons 2024
  ```

- **API-Football 历史比赛**（与伤停/赔率/积分同源，Mongo 用）  
  ```bash
  python main.py ingest-api-history --seasons 2024
  ```  
  若用 Mongo，可加 `--sync-mongo` 同步到 MongoDB。

### 2. 未来赛程（仅当该年还有未开赛时）

```bash
python main.py ingest-api-upcoming --seasons 2024
```

---

## 二、预测与回填

### 3. 对已完赛但无预测的场次落库预测

```bash
python main.py backfill-predictions --years 2024
```

### 4. 补 API 预测（Mongo：已有预测但缺 API 预测的场次）

```bash
python main.py fill-api-predictions --years 2024
```

### 5. 可选：强制重算该年所有预测（模型 + API + 融合）

```bash
python main.py repredict-for-all --years 2024
```

---

## 三、竞彩相关（若使用竞彩看板）

### 6. 拉取该年竞彩赛程到 `jingcai_match_analysis`

```bash
python main.py jc-batch-year --year 2024
```

### 7. 回填 API Football 的 fixture_id（便于统计与预测）

```bash
python main.py jc-match-analysis-backfill-fixture-id --year 2024
```

若仍有「有英文名但 API 无匹配」的场次（如亚洲杯、德乙、荷乙、队名差异），可在 `data/jingcai_fixture_id_override.json` 中手动填写：key = `sporttery_match_id`（从 `jc-match-analysis-fixture-id-handling --year 2024 --export data/unmatched_2024.csv` 导出得到），value = API-Football 的 fixture id。保存后再次执行上述 backfill 命令即可写回库。

### 8. 对该年竞彩日做模型预测并写入 `jc_predictions`

```bash
python main.py predict-jc-from-self-improvement --year 2024 --include-finished
```

### 9. 拉取该年竞彩场次的单场统计（射门/控球等）

```bash
python main.py statistics-api --jingcai-years 2024 --merge
```

---

## 四、辅助数据（按需）

### 10. 积分榜并回填每场主客队排名

```bash
python main.py standings-backfill --seasons 2024
```

### 11. 伤停（按 DB 中该年比赛日拉取）

```bash
python main.py injury-api-by-db --years 2024
```

### 12. 阵容

```bash
python main.py lineups-by-db --years 2024
```

### 13. 赔率

```bash
python main.py odds-api-by-db --years 2024
```

### 14. 历史交锋

```bash
python main.py h2h-backfill --years 2024
```

---

## 五、模型与评估（可选）

### 15. 样本足够时重训校准与 ML

```bash
python main.py refresh-models
```

### 16. 主库 + 竞彩一起重算并跑评估

```bash
python main.py refresh-and-eval --years 2024,2025,2026
```

---

## 快速清单（仅 2024 主库 + 竞彩）

```bash
# 主库
python main.py ingest-fd --seasons 2024
python main.py ingest-api-history --seasons 2024
python main.py backfill-predictions --years 2024
python main.py fill-api-predictions --years 2024

# 竞彩
python main.py jc-batch-year --year 2024
python main.py jc-match-analysis-backfill-fixture-id --year 2024
python main.py predict-jc-from-self-improvement --year 2024 --include-finished
python main.py statistics-api --jingcai-years 2024 --merge

# 积分榜
python main.py standings-backfill --seasons 2024
```

其他年份把 `2024` 换成对应年份即可；多年份用逗号分隔，如 `--seasons 2023,2024`、`--years 2023,2024`。
