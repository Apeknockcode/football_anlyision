# 为什么有这么多场次被「跳过」

根据 `jingcai_match_analysis` 做预测时，**跳过的唯一主要原因**是：**主队或客队在主库 `teams` 表里解析不到**（提示「主队名未解析」或「客队名未解析」）。

---

## 一、跳过原因说明

预测流程会：

1. 从 `jingcai_match_analysis` 读出该日所有场次（不按联赛过滤）
2. 用 `data/jingcai_team_name_mapping.json` 和 `jingcai_teams` 把竞彩中文名映射成主库英文名
3. 用 **`resolve_team_by_name`** 到主库 **`teams`** 表里查这支队伍
4. **若主库没有这支队伍** → 该场**跳过**，不会写入 `jc_predictions`

因此：**主库里目前只有五大联赛（英超/西甲/意甲/德甲/法甲）等已入库联赛的球队**，其它联赛的球队在 `teams` 里不存在，就会整场被跳过。

---

## 二、典型被跳过的联赛（主库无该联赛球队）

| 联赛 | 说明 |
|------|------|
| 日职 / 日乙 | 主库未入库 J 联赛球队 |
| 韩职 | 主库未入库 K 联赛球队 |
| 澳超 | 主库未入库 A-League 球队 |
| 美职 | 主库未入库 MLS 球队 |
| 德乙 / 法乙 / 荷甲 / 荷乙 / 英冠 / 葡超 / 瑞超 等 | 主库未入库这些联赛的球队 |
| 欧锦赛21 / 金杯赛 / 俱世界杯 等 | 国家队或非五大联赛俱乐部，主库无对应球队 |

这些场次会一直显示「主队名未解析」或「客队名未解析」，直到主库里有对应球队。

---

## 三、能成功预测的场次

只有**主客队都能在主库 `teams` 表里按名称解析到**的场次才会写入预测，例如：

- 英超、西甲、意甲、德甲、法甲（五大联赛）
- 与五大联赛共用球队的杯赛（如德国杯、意大利杯、足总杯等，队名已在主库）

所以你会看到：**总场次很多，但「新增预测」只来自五大联赛（及少数杯赛）**，其余都是因主库没有该队而跳过。

---

## 四、想减少跳过、覆盖更多联赛该怎么做

要让日职、韩职、澳超、德乙、美职等也出预测，需要：

1. **把这些联赛的球队和比赛入库到主库**  
   用你现有的 ingest（如 API-Football、football-data 等）拉取并写入：
   - `teams` 表：该联赛的球队（名称与主库一致或可通过映射对上）
   - `matches` 表：该联赛的比赛（用于模型算近期表现）

2. **保证队名能对上**  
   - 竞彩侧：`jingcai_team_name_mapping.json` / `jingcai_teams` 里要有「竞彩中文名 → 主库英文名」的映射  
   - 主库侧：`teams.name` 或 `teams.name_zh` 要与映射后的名称一致，`resolve_team_by_name` 才能解析到

3. **无需改预测逻辑**  
   当前预测逻辑已经会对**所有**从 `jingcai_match_analysis` 读出的场次尝试预测；只要主库能解析到主客队，就会写入，与联赛无关。

---

## 五、小结

| 现象 | 原因 |
|------|------|
| 总场次很多，但「跳过」很多 | 主库 `teams` 里没有这些场次的主/客队（多为非五大联赛） |
| 只有五大联赛有预测 | 目前只对五大联赛（及共用球队的杯赛）做了 ingest，主库只有这些队 |
| 想日职/韩职/澳超等也有预测 | 先对这些联赛做 ingest，把球队和比赛写入主库，并做好队名映射 |

要确认某天哪些场次被跳过、具体原因，可跑：

```bash
python3 main.py predict-jc-from-self-improvement --date 2025-04-12 --include-finished --verbose
```

输出里会逐场标明「主队名未解析」或「客队名未解析」。
