# 2026 年比赛列表单场推荐：以 2021–2025 年数据为辅提高命中率

## 目标

提高**2026 年比赛列表**的单场推荐命中率，使用 **2021、2022、2023、2024、2025** 年的历史数据作为辅助，导出「细分命中率」与「联赛达 70% 所需最低概率」，在 2026 的推荐与列表中应用。

## 一键执行

```bash
python3 main.py jc-recap-auxiliary-for-2026
```

该命令会：

1. 用 **2021-01-01～2025-12-31** 的已完赛预测，导出：
   - `data/jc_rec_segment_hit_rates_2021_2025.json`（联赛×推荐类型×概率区间 的命中率）
   - `data/jc_league_rec_params_2021_2025.json`（各联赛单场推荐命中率及达 70% 目标所需最低概率）
2. 用上述细分命中率，对 **2026 年** 数据再跑一次评估，输出 2026 年的单场推荐命中率。

## 2026 列表如何用这些数据

- 默认已开启 **JC_REC_FOR_2026_USE_AUXILIARY=true**。
- 当**日期为 2026** 时（今日推荐或 2026 比赛列表）：
  - 单场推荐会加载 **2021–2025 导出的细分命中率**：在历史表现差的「联赛×推荐类型×概率区间」改为推荐胜/负。
  - 联赛门槛会加载 **2021–2025 导出的联赛参数**：仅保留 `rec_prob >= 该联赛 min_prob_70` 的场次，更贴近 70% 目标。

其他年份（如 2025）仍使用默认的 `JC_REC_SEGMENT_STATS_PATH` / `JC_REC_LEAGUE_PARAMS_PATH`（若已配置）。

## 配置（可选）

| 配置项 | 含义 | 默认 |
|--------|------|------|
| `JC_REC_FOR_2026_USE_AUXILIARY` | 2026 年是否用 2021–2025 导出的参数 | `true` |
| `JC_REC_AUXILIARY_SEGMENT_STATS_PATH` | 辅助年细分命中率 JSON 路径 | `data/jc_rec_segment_hit_rates_2021_2025.json` |
| `JC_REC_AUXILIARY_LEAGUE_PARAMS_PATH` | 辅助年联赛参数 JSON 路径 | `data/jc_league_rec_params_2021_2025.json` |

## 手动分步（可选）

```bash
# 1) 仅用 2021–2025 导出细分与联赛参数
python3 main.py jc-predictions-eval --date-from 2021-01-01 --date-to 2025-12-31 \
  --export-segment-stats data/jc_rec_segment_hit_rates_2021_2025.json \
  --export-league-rec-params data/jc_league_rec_params_2021_2025.json

# 2) 用上述细分评估 2026 年单场推荐命中率
python3 main.py jc-predictions-eval --year 2026 \
  --segment-stats data/jc_rec_segment_hit_rates_2021_2025.json
```

## 2026 年单场推荐命中率前后对比（本次执行结果）

对 **2026 年** 已完赛 712 场做了两次评估：

| 评估方式 | 单场推荐命中 | 命中率 | 说明 |
|----------|--------------|--------|------|
| **前（基线）** | 399 / 712 | **56.0%** | 不使用 2021–2025 细分覆盖，仅当前启发式 |
| **后（用 2021–2025 细分）** | 399 / 712 | **56.0%** | 使用 `--segment-stats data/jc_rec_segment_hit_rates_2021_2025.json` |

本次跑数下，前后单场推荐命中率一致，说明在这 712 场里，应用 2021–2025 细分覆盖后**没有改变统计到的命中场次**（要么没有落入会被覆盖的细分，要么覆盖后命中/未命中数量与基线相同）。

2026 列表仍会因辅助年参数而受益：

- **联赛门槛**：仅展示 `rec_prob >= 该联赛 min_prob_70` 的场次，高置信子集更易接近 70% 命中率（例如本次 2026 中「推荐概率≥60%」子集为 72.5%，「≥70%」为 90.9%）。
- **细分覆盖**：新产生的 2026 推荐在「历史差细分」会改为推荐胜/负，减少在易错场景的误推。

复跑对比命令：

```bash
# 前（基线）
python3 main.py jc-predictions-eval --year 2026

# 后（用 2021–2025 细分）
python3 main.py jc-predictions-eval --year 2026 --segment-stats data/jc_rec_segment_hit_rates_2021_2025.json
```

## 说明

- 辅助年（2021–2025）需在 `jc_predictions` 与 `jingcai_match_analysis` 中已有预测且已填比分，否则导出的细分/联赛参数样本偏少。
- 2026 年列表与「今日推荐」在日期为 2026 时自动使用上述参数，无需再改业务代码。
