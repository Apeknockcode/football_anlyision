## 7. 本次已实现

- **config**：新增 `SINGLE_REC_RQ_MIN_PROB_LET_FU`（默认 **0.65**），让负仅当概率 ≥ 0.65 时才推荐，否则在 gap 内优先出「负」。
- **db/self_improvement.py**：`_single_rec_label_and_prob` 与评估循环中，对「让球保守」判断使用上述让负单独门槛。

全量评估仍约 52.8%；若需进一步压让负误推，可将 `SINGLE_REC_RQ_MIN_PROB_LET_FU` 调为 **0.66** 或 **0.68**（环境变量或 config 默认值）后重跑评估。
