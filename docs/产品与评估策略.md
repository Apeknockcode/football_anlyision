# 产品与评估策略

## 主推高置信度

- **含义**：仅对「高置信度」预测做主推，低置信度（样本不足或期望进球接近）标为仅供参考。
- **实现**：
  - 预测输出含 `confidence`（high/low）与 `high_confidence`（max(主/平/客概率) ≥ 0.45）。
  - **API**：`GET /predictions?high_confidence_only=true` 仅返回高置信度场次。
  - **竞彩评估**：`jc-predictions-eval` 输出 `n_high_conf`、`outcome_accuracy_high_conf`，便于看「只推高置信」时的命中率。
- **建议**：前端/产品默认只展示或主推 `high_confidence=true` 的场次，其余折叠或标「仅供参考」。

## 按联赛分层

- **含义**：展示与评估都支持按联赛拆分，便于分联赛调参与看单联赛表现。
- **实现**：
  - **API**：`GET /predictions?league=英超` 或 `league=Premier League` 仅返回该联赛场次。
  - **评估**：`predict-eval --by-competition`、`jc-predictions-eval` 的 `by_league` 均按联赛输出命中率与 MAE。
- **建议**：产品可提供联赛 Tab 或筛选，评估时按联赛对比以识别弱联赛并调 `predict_league_params.json`。

## 按联赛评估

- **命令**：
  - 主库预测：`python main.py predict-eval --by-competition`（按赛事分组准确率）。
  - 竞彩预测：`python main.py jc-predictions-eval --year 2025`（输出含 `by_league` 列表）。
  - 一键全量：`python main.py eval-all`（含 predict-eval、predict-eval --by-competition、recap、recap --by-competition）。
- **指标**：各联赛的 `n`、`outcome_accuracy`、`outcome_correct`（及竞彩的 `outcome_accuracy_high_conf`），用于决定是否对某联赛单独调参或主推。

## 数据质量与规则（相关）

- **赔率质量与时效**：见 [可补充数据与模型提升.md](可补充数据与模型提升.md)；配置 `PREDICT_ODDS_IMPLIED_SUM_MIN/MAX`、`PREDICT_ODDS_MAX_AGE_HOURS` 可过滤异常或过旧赔率。
- **队名/ID 解析率**：竞彩预测返回 `resolution_rate`、`unresolved_sample`（API `/api/jc-predict/run`、命令行单日/批量）；解析率低时可补 `jingcai_team_name_mapping.json` 或 `jc_teams_map_to_api_football`。
- **边界场次规则**：预测输出 `is_boundary`（势均力敌且主队略优），产品可标为「边界场次，仅供参考」或单独展示。
