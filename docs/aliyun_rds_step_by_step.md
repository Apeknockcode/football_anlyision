# 阿里云数据库（RDS）从零操作步骤

按顺序做即可，做完后项目会连到阿里云 MySQL，数据存在云上。

---

## 第一步：登录阿里云

1. 打开 https://www.aliyun.com/ ，登录你的账号。
2. 若没有账号，先注册并完成实名认证（用 RDS 需要）。

---

## 第二步：开通并创建 RDS 实例（MySQL）

1. 在阿里云控制台顶栏搜索 **「RDS」** 或 **「云数据库」**，进入 **云数据库 RDS 控制台**。
2. 地域选一个离你近的（如 **华东1（杭州）**）。
3. 点击 **「创建实例」**：
   - **计费方式**：选「按量付费」（用多少扣多少，不用可释放）。
   - **引擎**：选 **MySQL**。
   - **版本**：选 **MySQL 8.0**。
   - **系列/规格**：选 **基础版**、**1 核 1GB** 即可（个人用够用）。
   - **存储**：默认 20GB 即可。
4. 设置 **账号**：
   - 高权限账号名：如 `admin`（自己记住）。
   - 密码：设一个强密码并记下来（后面要填到项目里）。
5. 点击 **「立即购买」** / **「创建」**，等几分钟实例状态变为 **运行中**。

---

## 第三步：创建数据库、并放行你的 IP

1. 在 RDS 实例列表里，点你刚创建的实例 **「管理」**。
2. **创建数据库**（若没有默认库）：
   - 左侧点 **「数据库管理」** → **「创建数据库」**。
   - 数据库名填：`football`（或任意英文名，记住即可）。
   - 字符集：`utf8mb4`。
   - 点确定。
3. **放行访问 IP（白名单）**：
   - 左侧点 **「数据安全性」** → **「白名单设置」**。
   - 默认有一个 `127.0.0.1`，**不够**，需要加你当前上网的 IP：
     - 点 **「添加白名单分组」**；
     - 分组名：`my_pc`；
     - 白名单：填 **你本机公网 IP**（在浏览器搜「我的IP」即可看到，例如 `123.45.67.89`）；
     - 或临时图省事可填 `0.0.0.0/0`（允许所有 IP，仅测试用，不建议长期）。
   - 保存。
4. **查连接地址**：
   - 在实例 **「基本信息」** 里找到 **「内网地址」** 或 **「外网地址」**。
   - 你本机连阿里云，一般要用 **「外网地址」**（例如 `rm-xxxxx.mysql.rds.aliyuncs.com`）。
   - 端口一般是 **3306**。

把下面几项记下来，下一步要用：

- 外网地址：`____________`
- 端口：`3306`
- 数据库名：`football`（或你起的名字）
- 高权限账号：`____________`
- 密码：`____________`

---

## 第四步：在项目里填连接信息

1. 打开项目根目录下的 **`.env`** 文件（没有就新建一个）。
2. 增加或修改这一行（把括号里的换成你记下的）：

```bash
# 格式：mysql+pymysql://用户名:密码@外网地址:3306/数据库名
DATABASE_URL=mysql+pymysql://admin:你的密码@rm-xxxxx.mysql.rds.aliyuncs.com:3306/football
```

注意：

- 密码里若有 `@`、`#`、`:` 等特殊字符，需要做 URL 编码，或先在 RDS 里把密码改成只有字母数字。
- 把 `rm-xxxxx.mysql.rds.aliyuncs.com` 换成你控制台里看到的 **外网地址**。

3. 安装 MySQL 驱动：

```bash
cd /Users/taotao/Documents/QiyuanSymbol/football_anlyision
pip install pymysql
```

4. 建表（让项目在云数据库里创建好表结构）：

```bash
python main.py list
```

如果没报错、能列出比赛或提示「暂无数据」，说明数据库已经连上并在用阿里云了。

---

## 第五步：确认是否在用云库

- 再跑一条会写数据的命令，例如：`python main.py ingest --max-matches 1`
- 到阿里云 RDS 控制台 → 该实例 → **「DMS 登录」** 或 **「登录数据库」**，用同一账号密码登录，在库 `football` 里能看到 `matches`、`competitions` 等表，说明数据已经在云上。

---

## 常见问题

- **连不上、超时**：检查 RDS 白名单里是否加了你这台电脑的 **公网 IP**（用外网地址时必须）。
- **Access denied**：账号或密码错了，或数据库名填错，对照控制台再改 `.env`。
- **不想用云了**：把 `.env` 里的 `DATABASE_URL` 删掉或注释掉，项目会恢复用本机 `data/football.db`。
